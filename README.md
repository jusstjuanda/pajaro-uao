# Pájaro — Aves del campus UAO en Realidad Aumentada

App web de RA para avistar las aves del campus de la Universidad Autónoma de Occidente (Cali),
basada en la Guía ilustrada de aves del campus UAO 2023. Sitio estático en `PaginaPajaro/wwwroot`.

Interacciones RA: Avistar, Binoculares, Llamar, Comedero, Foto de campo, Quiz y Tamaño real (WebXR).
Requiere HTTPS y permiso de cámara/movimiento en el celular.
